# 快速上手

## 1. 安装

### IDE 本身

去 [Releases](https://github.com/JiHuiYiYou/JiHuiYiYou-IDE/releases) 下安装包
（`JHYY-IDE-x.y.z-x64-setup.exe`）。目前只有 Windows x64 —— 也是唯一构建并验证过的平台。

> 安装包**没有代码签名**，所以 Windows SmartScreen 会拦一下。
> 选"更多信息 → 仍要运行"。

也可以从源码构建：

```bash
git clone https://github.com/JiHuiYiYou/JiHuiYiYou-IDE.git
cd JiHuiYiYou-IDE
npm install
npm run dev        # 开发
npm run dist       # 打 NSIS 安装包 → release/
```

### 编译器

IDE **需要** `jhyy.exe` —— 每次编译、每条诊断都由它裁决。IDE 按这个顺序找：

1. IDE 设置里配的路径
2. 环境变量 `JHY_EXE`
3. `../JiHuiYiYou/compiler/build/bin/jhyy.exe` —— 开发构建，在本仓库旁边
4. `C:\Program Files\JHYY\bin\jhyy.exe` —— 官方安装版
5. `PATH` 上的 `jhyy.exe`

语言的官方安装包在[编译器仓库](https://github.com/JiHuiYiYou/JiHuiYiYou-compiler)。
把那个仓库 clone 成**本仓库的兄弟目录**，第 3 步就能零配置找到编译器：

```
coding/
├── JiHuiYiYou/          ← 编译器仓库
└── JiHuiYiYou-IDE/      ← 本仓库
```

> **编译器要一个能用的 gcc。** 链接是 MSYS2 的
> `mingw-w64-ucrt-x86_64-gcc` 干的。**千万别用** Git Bash 自带的 MinGW gcc
> （`C:\Program Files\Git\mingw64\bin\gcc.exe`）—— 它链不了 PE，而且失败时
> **一个字都不吭**。

## 2. 打开一个程序

`File → Open…` 任意 `.jhyy` 文件。最小的例子：

```rust
extern fn printf(fmt: *u8, val: i32) -> i32;

fn main_jhyy() -> i32 {
    let mut total: i32 = 0;
    for i in 0..10 {
        total = total + i;
    }
    printf("total = %d\n", total);
    total
}
```

按 **运行**（或 `F5`）。你会看到：

- **输出** —— 程序的 stdout / stderr，以及退出码
- **问题** —— 编译器自己的诊断，`file:line:col: error: …`

底部面板**每次启动都是收着的** —— 你要才弹：**运行**弹到「输出」页，
**检查**（`Ctrl+Shift+D`）弹到「问题」页。`Ctrl+J` 开关面板本身。
它只在**编辑器下面**，聊天侧栏始终是整列的，不会被面板压小。

退出码就是 `main_jhyy` 的返回值 —— 语言的回归套件就是这么断言行为的，IDE 也一样。

> JHYY **没有** `print` 内建。用 `extern fn printf` 或 `io::std_io_print`。

## 3. 工作台

### 标题栏

窗口**没有原生边框** —— 标题栏是 IDE 自己画的，跟 VS Code 一个路数：

- **文件 / 编辑 / 选择 / 查看 / 转到** —— 菜单。每一项都跟快捷键**从同一张命令表生成**，
  所以菜单里标出来的快捷键一定就是真能按的那个。
- **命令中心** —— 中间那个搜索框。点它（或按 `Ctrl+Shift+P`）打开**命令面板**：
  打几个字，选一条命令，就完事了。
- **🧩** —— 切换块视图。**💬** —— 切换聊天侧栏。**▣** —— 布局下拉
  （菜单栏 / 侧栏 / 面板 / 状态栏）。

### 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+Shift+B` | 切换 块视图 / 文本视图 |
| `Ctrl+S` / `Ctrl+O` | 保存 / 打开 |
| `F5` / `Shift+F5` | 运行 / 停止 |
| `Ctrl+Shift+D` | 检查 |
| `Ctrl+J` | 显示/隐藏 底部面板 |
| `Ctrl+Shift+M` / `Ctrl+Shift+U` | 问题 / 输出 |
| ``Ctrl+` `` | 终端 |
| `Ctrl+Alt+I` | 聊天 |

完整表在**查看**菜单和命令面板里。

### 文本视图

一个正常的编辑器：语法高亮、括号匹配、自动补全、`Ctrl+F` 搜索、补全、悬停文档，
以及实时诊断（停手约 600ms 后编译器会检查一遍 —— 那次检查跳过链接，所以很快）。

文件开在**标签页**里 —— 开第二个文件不会把第一个顶掉，每个标签各自记着自己的
内容、脏状态和块。小黑点是**按内容算**的（跟 VS Code 一样），
所以撤销回上次保存的版本，小圆点自动消失。

### 块视图

同一个程序的可拖拽块形态。块覆盖入门子集 —— 变量、算术、`if`/`else`、
`while`/`for`、函数、结构体、枚举 + `match`、`printf`。

- **工具箱第一屏是「入门」** —— 函数、打印、调用、数字/字符串、变量、返回、
  **C 函数声明**。写第一个程序要用的块全在这一屏，不用在六个分类里翻。
  后面才是变量 / 运算 / 控制流 / 函数 / 类型 / 原始代码。
- **C 函数声明有现成的块** —— 每个 JHYY 程序的第一行都是
  `extern fn printf(fmt: *u8, val: i32) -> i32;`，以前只能用「原始代码」逃生舱
  手打。现在拖一个**「C 函数声明」**块出来就行：上面那个下拉直接选
  `printf` / `puts` / `malloc` / `free` / `exit`，参数表和返回类型会自动填好
  （想改也能改）。
- **表达式一行两个孔** —— `a + b` 是**一行**（不是上下两行），
  运算符在**中间**（`[a] [+] [b]`），赋值同理（`[目标] = [值]`）。
- **类型是下拉** —— `i8`/`i16`/`i32`/…/`bool` 直接选，不用手打
  （`let x = 0` 这种不写类型的也选「（不写）」）。
- **`printf` 是专用块** —— 一个格式串下拉 + 一个值孔，**不用**拖「实参」套「实参」。
- **有现成的「读入」块** —— `scanf("%d", &x)` 一块搞定（取地址由块自己加），
  C 函数声明的下拉里也有 `scanf` 这个预设。
- **每个容器都有标签** —— 「成立时」/「否则」/「循环体」/「函数体」/「参数」/
  「字段」/「变体」/「分支」/「元素」，不会再分不清哪个是哪个。
- **块画布满整个编辑区，代码编辑器整个消失** —— 两者从不同时占屏。
  用 🧩 按钮、`Ctrl+Shift+B` 或命令面板切。切换时两边都**保留状态** ——
  画布保留缩放和平移，编辑器保留撤销历史和光标位置。
- **块 → 文本**是实时的：拖一下块，文本就跟着变。
- **文本 → 块**发生在你切回块视图时（每敲一个键就重建块，画布会抖到没法用）。
  块过期时 🧩 按钮上会冒一个小圆点。
- 块子集表达不了的语法会变成一个**不透明块**，里面装着原始源码。
  挪它、删它都行 —— 只要你别动它，那部分代码**逐字节**往返无损。

### Claude Code

右侧栏里的聊天在跟你机器上的 `claude` CLI 说话。它能读写项目文件；当你正盯着看的文件
被它改了，IDE 会重新加载（如果你有未保存的改动，它会先问一句 ——
绝不会悄悄覆盖你的活儿）。

细节见 [Claude Code](Claude-Code.zh-CN)，包括 Claude 怎么自己去跑 `jhyy_check`。

### 面板和终端

底部面板装着三个页签：

- **问题** —— 编译器的诊断。点一条直接跳到那一行那一列。
- **输出** —— 程序的 stdout / stderr 和编译器自己的日志，按来源上色。
- **终端** —— 一个真 shell（默认 **MSYS2 bash**；也有 PowerShell 和 `cmd`）。
  起始目录是你打开的那个文件所在的目录。

> ⚠️ 终端跑在**管道上，不是 PTY** —— 所以 `vim`、`top` 这类全屏 TUI 程序跑不了。
> 别的都好使，而且中文 Windows 上输出是 UTF-8 的。

跟 VS Code 的集成终端一样，终端**会把 IDE 执行的命令也显示出来** ——
按**运行**，终端里是 `> jhyy compile "…"` 加上程序的输出。

没打开文件时，编辑器显示的是**欢迎页**（打开 / 新建），不是一段示例代码。
