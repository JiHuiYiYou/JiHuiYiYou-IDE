# 块子集 —— 哪些语法有块，哪些是逃生舱

JHYY 是一门挺大的语言（泛型、闭包、指针、切片、`match`、`defer`、`asm!`、
`Cap<T>`、`PhantomData<T>`……）。**拖块不可能覆盖全部** —— 硬凑出来的块会很别扭，
而且会让"块"和"代码"变成两套语义。

所以分两层：

- **块子集** —— 入门要用的语法，有正经的块。
- **逃生舱（不透明块）** —— 其余语法，原样保留，不丢。

## 逃生舱怎么工作

块子集之外的语法，在块视图里变成一个 **`原始代码` 块**（`jhyy_opaque`），
里面装的是那一段源码**原文**。

- 手写的代码在块视图里**看得见**（不会被"切回块视图"弄丢）
- 块 → 文本时，不透明块**原样吐出**那段源码 → **往返无损**
- 只有你**主动改动或删除**不透明块时，那部分才会变

不透明块里的换行写成 `\n`、反斜杠写成 `\\`（单行文本框放不下多行）。

## 有块的语法

| 类别 | 块 | 对应的 AST |
|---|---|---|
| 变量 | 声明变量（可勾选 `mut`、可填类型） | `let` |
| 变量 | 赋值 | `assign` |
| 变量 | 引用变量 | `ident` |
| 字面量 | 数字 / 字符串 / 布尔 / 字符 | `int` `float` `string` `bool` `char` |
| 运算 | 二元运算（+ - * / % == != < > <= >= && \|\| & \| ^ << >>） | `binary` |
| 运算 | 一元运算（- ! ~） | `unary` |
| 运算 | 类型转换 `as` | `cast` |
| 运算 | 取字段 `.x` | `field` |
| 运算 | 取下标 `[i]` | `index` |
| 运算 | 数组字面量 | `array_lit` |
| 控制流 | if / else（if 是表达式） | `if` |
| 控制流 | while | `while` |
| 控制流 | for（区间形式） | `for` |
| 控制流 | break / continue | `break` `continue` |
| 控制流 | match（模式写在分支块里） | `match` |
| 函数 | 定义函数（参数、返回类型、函数体） | `func_decl` |
| 函数 | 调用 | `call` |
| 函数 | 调用模块里的函数 `mod::fn(...)` | `qualified_call` |
| 函数 | 打印（`printf`） | `call` |
| 类型 | 结构体定义 | `type_decl` + `struct_def` |
| 类型 | 结构体字面量 | `struct_lit` |
| 类型 | 枚举定义 | `type_decl` + `enum_def` |
| 类型 | 枚举变体 | `enum_variant` |
| 类型 | 类型别名 | `type_decl` |
| 类型 | import | `import_decl` |
| 逃生舱 | 原始代码 | 任意 |

### 语句形态 vs 值形态

一个块**不能**既是值块（有输出连接）又是语句块（有前后连接）——
这是 Blockly 的硬规则。所以有些语法有两个块：

| 语法 | 值形态（能接在值的位置） | 语句形态（能接在语句的位置） |
|---|---|---|
| 调用 | `jhyy_call` | `jhyy_call_stmt` |
| 限定调用 | `jhyy_qcall` | `jhyy_qcall_stmt` |
| 赋值 | `jhyy_set_val` | `jhyy_set` |
| if | `jhyy_if_val` | `jhyy_if` |
| match | `jhyy_match_val` | `jhyy_match` |
| 表达式语句 | —— | `jhyy_expr_stmt`（求值但丢弃结果） |

反编译时按**位置**选变体，编译时变体归一。

## 没有块的语法（逃生舱）

| 语法 | 为什么 |
|---|---|
| 泛型 `Pair<T>` / turbofish `max::<i32>(…)` | 泛型实参要能是类型，块的输入槽表达不了"类型" |
| 闭包 `\|x: i32\| { x + 1 }` | 闭包不能捕获外层变量，块化收益低、别扭度高 |
| 指针 `*p` / `&x` / `&mut x` | 要能表达类型标注和算术，块化很碎 |
| 切片 `[*]i32` / `s[1..3]` | 切片类型和子区间混在取值位置，块化后反而更难读 |
| `defer f();` | 语句形态的特殊调用，逃生舱够用 |
| `asm!("nop")` | 只有单个字符串字面量，块化没意义 |
| `volatile T` | 类型限定符 |
| 属性 `#[inline]` `#[naked]` `#[link_section("…")]` `#[no_std]` | 声明级元信息 |
| `extern fn` | 需要精确的参数类型和符号名 |
| `const NAME: [T; N] = […]` | 顶层常量数组，元素必须是常量 |
| `Cap<T>` / `PhantomData<T>` | ZST 标记类型，出现在类型位置 |
